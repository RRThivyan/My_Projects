SmartReport AI is an intelligent medical report summarization system that transforms complex laboratory PDF reports into clear, doctor-friendly summaries using Azure OpenAI. The application supports both digital PDFs and scanned documents through OCR capabilities.

## ✨ Features

### 🚀 Core Capabilities
- **Dual Extraction Methods**: Automatic detection of digital text vs. scanned documents
- **Intelligent OCR**: Uses Docling with PyPDFium2 backend for accurate text extraction from scanned PDFs
- **Medical-Specific Processing**: Specialized prompt engineering for laboratory reports
- **Multi-Platform**: Both command-line (`extract.py`) and web interface (`app.py`) options
- **Batch Processing**: Command-line tool supports automated processing with timestamped outputs

### 🎨 Web Interface Features
- **Modern UI**: Gradient-based design with responsive cards and animations
- **Real-time Processing**: Visual progress indicators for each processing stage
- **Secure Upload**: Files deleted immediately after processing
- **Download Options**: Save summaries as text files with timestamped names
- **Customizable Length**: Adjustable summary length (100-3000 tokens)

### 🔧 Technical Features
- **Azure OpenAI Integration**: Secure API calls with configurable parameters
- **Environment Configuration**: All settings managed via `.env` file
- **Error Handling**: Robust error handling for PDF processing and API calls
- **Text Cleaning**: Advanced regex-based cleaning to remove artifacts and normalize text

## 🏗️ Architecture

```mermaid
graph LR
    A[PDF Input] --> B{Digital PDF?}
    B -->|Yes| C[PyMuPDF Extraction]
    B -->|No| D[Docling OCR]
    C --> E[Text Cleaning]
    D --> E
    E --> F[Azure OpenAI]
    F --> G[Doctor Summary]
    G --> H[Output/Display]
The system follows a modular pipeline:

PDF Analysis: Detects if PDF contains digital text

Text Extraction: Uses appropriate method (direct or OCR)

Text Cleaning: Removes artifacts and normalizes content

AI Processing: Azure OpenAI generates structured summary

Output: Formats and delivers results

Clone the repository (if applicable):

Create and activate virtual environment:

bash

bash

# Edit .env with your credentials
⚙️ Configuration
Environment Variables (.env)
Create a .env file in the project root:

ini
# Azure OpenAI Configuration
AZURE_OPENAI_ENDPOINT=your_endpoint_here
DEPLOYMENT_NAME=your_deployment_name
API_VERSION=2025-01-01-preview
API_KEY=your_api_key_here

# Processing Settings
TEMPERATURE=0.1
MAX_TOKENS=3000

# File Paths (for extract.py)
PDF_PATH=C:/path/to/your/pdf.pdf
OUTPUT_DIR=outputs
Configuration Options
TEMPERATURE: Controls creativity (0.1 recommended for medical accuracy)

MAX_TOKENS: Maximum length of AI-generated summary

PDF_PATH: Default PDF for command-line processing

OUTPUT_DIR: Directory for generated files

🐛 Troubleshooting
Common Issues
1. "ModuleNotFoundError"
bash
# Ensure virtual environment is activated and dependencies installed
pip install -r requirements.txt
2. Azure OpenAI Connection Errors
Verify .env file contains correct credentials

Check Azure portal for deployment status

Ensure API version is correct

3. PDF Processing Issues
For scanned documents, ensure docling is properly installed

Check PDF file integrity

Try converting PDF to images and back if OCR fails

4. Memory Issues with Large PDFs
The system caps extraction at 200,000 characters

Consider splitting very large reports

Monitor system memory during OCR processing

Performance Tips
Digital PDFs: Process in ~5-10 seconds

Scanned PDFs: OCR adds 10-30 seconds depending on page count

Network: Azure OpenAI calls typically take 2-5 seconds

Hardware: OCR benefits from multi-core CPUs
